## Resources

### Probabilistic Machine Learning: An Introduction

**Type:** Textbook

**Access:** Open access

**Level:** Intermediate → Advanced

**Format:** Book (author-hosted free PDF) + code notebooks

Kevin Murphy's introduction to machine learning through probabilistic modeling. It covers the mathematical background, linear and logistic regression, deep neural networks, and unsupervised and transfer learning, with Colab notebooks that reproduce most figures. The free PDF is the author's draft (CC-BY-NC-ND); the printed edition is sold separately.

**Best for:** Learners who want a rigorous, modern ML foundation beyond a first course.

**Prerequisites:** Linear algebra, calculus, basic probability and some Python.

[Open resource →](https://probml.github.io/pml-book/book1.html)
