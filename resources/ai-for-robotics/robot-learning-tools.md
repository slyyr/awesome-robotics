## Resources

### LeRobot

**Type:** Open-source library + documentation

**Access:** Free

**Level:** Intermediate

**Format:** Docs + tutorials + Colab notebooks

Hugging Face's PyTorch library for real-world robot learning. It walks through teleoperating, recording datasets, training imitation-learning and vision-language-action policies (such as ACT and SmolVLA) and evaluating in simulation benchmarks. Colab notebooks and Hub datasets let you start without owning a robot.

**Best for:** Python/PyTorch users who want hands-on robot learning, with or without hardware.

**Prerequisites:** Python and basic PyTorch; a GPU (for example via Colab) for training.

[Open resource →](https://huggingface.co/docs/lerobot/index)
