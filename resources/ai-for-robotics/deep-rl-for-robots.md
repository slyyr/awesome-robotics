## Resources

### Stanford CS224R: Deep Reinforcement Learning

**Type:** University course

**Access:** Free

**Level:** Intermediate → Advanced

**Format:** Lectures + slides + assignments

Graduate course on learning behavior from high-dimensional observations with deep neural networks. It covers imitation learning, Q-learning, practical deep RL implementation and reward learning, with an explicit emphasis on robotics and control.

**Best for:** Learners who have finished an introductory ML/deep learning course and want to see how robot policies are trained.

**Prerequisites:** Machine learning at CS229 level, deep learning basics (backpropagation, CNNs, transformers) and some familiarity with reinforcement learning.

[Open resource →](https://cs224r.stanford.edu)
